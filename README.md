# 루이푸리

서비스 목적과 미정 사항은 [프로젝트 맥락](docs/PROJECT.md), 개발 하네스 설치·검증·매일 사용할 프롬프트는 [SETUP](docs/ai/SETUP.md)을 참고한다.

현재는 신규 프로젝트의 개발 하네스만 구성되어 있다. 제품 소스·실행 서버·DB는 아직 없다.

Spec Kit을 별도로 전역 설치하지 않고 `python3 scripts/ai/specify.py setup`으로 프로젝트 실행 환경을 준비한다. Codex 채팅의 `$project-sdd <목표와 작업 범위>`로 명세 주도 개발을 시작한다. 팀원의 기본 도구·계정 조건과 역할 구성은 [SPEC_KIT](docs/ai/SPEC_KIT.md)을 참고한다.
