# HARNESS-001 — 공유 에이전트 준비 검사의 누락·잘못된 필드 탐지

상태: 해결됨(로컬 구현·검증·독립 리뷰 완료). 사용자 요청으로 만든 로컬 검증 이슈이며 GitHub 이슈가 아니다.

## 문제와 기대 결과

기존 doctor는 역할 4개만 보고 필수 필드의 진릿값만 확인했다. 공백 문자열·비문자열이 준비 완료로 통과하고 검증·보안·스택 자문 역할의 누락을 발견하지 못한다. 요청된 7개 역할과 진입 스킬을 실제 형식으로 검사하고 잘못된 준비 상태를 성공으로 보고하지 않아야 한다.

실제 제품 기능 대신 이 하네스 결함으로 명세 작성 → 설계·작업 → 구현 → 독립 검증·리뷰를 실행한다. 제품 코드·외부 서비스·커밋·푸시·배포는 범위 밖이다.
