# 결정 기록

## D-001 — 제품과 분리한 최소 하네스 (채택, 2026-10-29)

제품 스택이 없으므로 제품 manifest·가상 검증 명령·빈 API 문서를 만들지 않는다. Python 표준 라이브러리로 하네스를 검증하고 CI는 2026-11-01 사용자 결정으로 제외하며 추후 별도 추가한다. 근거: [F-002](FACTS.md#f-002--제품-스택과-실행-환경은-미정), [검증 코드](../../../scripts/ai/harness.py). 범위: 초기 하네스. 제품 스택 도입 시 실제 명령을 SETUP과 검증 스킬에 연결한다.

## D-002 — 공유 규칙과 개인 상태 분리 (채택, 2026-10-29)

공유할 규칙·스킬·도구 lock만 Git 대상으로 두고 세션·기계적 이벤트·브라우저 산출물·인증 상태는 로컬에 둔다. 의미 요약은 인계 스킬이 작성하고 스크립트는 검증·원자적 저장만 한다. 근거: [.gitignore](../../../.gitignore), [인계 스킬](../../../.agents/skills/project-handoff/SKILL.md). 범위: 이 프로젝트. 다른 컴퓨터의 팀원에게 인계할 때는 기록을 검토·정제해 명시적으로 전달해야 한다.

## D-003 — 훅 두 개와 도구 방식 (채택, 2026-10-29)

SessionStart의 짧은 안내와 PreCompact의 기계적 체크포인트만 등록한다. Stop 재진입이나 반복 테스트 비용이 없으며, 정당화할 실제 금지 사례가 없어 PreToolUse는 등록하지 않는다. Context7은 프로젝트 범위 원격 MCP 하나, Playwright는 버전을 고정한 프로젝트 로컬 CLI+Skills 하나만 사용한다. 근거: [SETUP](../SETUP.md), [공식 자료·출처](../UPSTREAM.md). 범위: 하네스. 실수나 정책·도구 지원이 바뀌면 필요성과 오탐 가능성을 다시 평가한다.

## D-004 — Spec Kit 실행 환경과 역할도 저장소에 포함 (대체됨 → D-005, 2026-11-03)

개인 CLI 설치만으로는 팀의 공유 하네스 요구를 충족하지 못한다. 프로젝트 전용 manifest·lock·wrapper, 역할 4개와 project-sdd 진입점을 공유 대상으로 구성한다. 기존 개인 `uv tool` 실행 방식은 이 결정으로 대체한다. 근거: [PF-001](PITFALLS.md), [당시 구성](https://github.com/louie-kury/louie-kury-back/blob/3e5d0fccb9cb7f83003ed0a740648b2467a921e7/docs/ai/SPEC_KIT.md). 범위: 명세 주도 개발 하네스. 모델 계정·기본 런타임과 각 사용자 신뢰 등록은 별도이며 실제 에이전트 호출과 OS별 실행은 구분해 검증한다.

결정을 바꾸면 기존 항목을 삭제하지 않고 `대체됨 → 새 ID`와 이유·날짜를 표시한다. 제품 아키텍처 결정은 아직 없다.

## D-005 — 사람이 선택하는 가벼운 개발 (채택, 2026-11-03)

사용자와 팀이 직접 개발 방향을 정하고 에이전트를 만들어가기로 했다. 미리 만든 에이전트 전부, 자동 단계 연결, Spec Kit, 터미널 승인 도구를 제거한다. 바이브 와이즈로 사용자의 선택·이유·미정 사항을 기록하며 합의한 부분만 개발한다. 세션·컨텍스트·기억과 Context7은 유지하고, Playwright도 사용자 선택으로 유지한다. 최종 PR 검토·머지는 사람이 한다. 근거: [현재 개발 흐름](../WORKFLOW.md), [설치 안내](../SETUP.md).

## D-006 — 메인과 네 담당자의 분업 (채택, 2026-11-03)

D-005의 등록 에이전트 없음 부분을 대체한다. 사용자가 메인·planner·implementer·tester·reviewer 다섯 역할을 정했다. planner는 필요한 초기 설계와 최종 문서 동기화, implementer는 테스트 제외 구현, tester는 구현 제외 테스트, reviewer는 서로 다른 호출의 코드 리뷰와 블랙박스 QA를 맡는다. 사람의 선택·이유와 가벼운 대화 승인 방식은 유지한다. [역할 기준](../WORKFLOW.md).
