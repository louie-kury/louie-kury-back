# 루이쿠리 Git 컨벤션

## 공통 타입

이슈 제목, 작업 브랜치명, 커밋 메시지, PR 제목에는 아래 여섯 가지 타입만 사용한다. 타입은 영문 소문자로 작성한다.

| 타입 | 사용 기준 |
| --- | --- |
| `feat` | 기능 추가 또는 변경 |
| `fix` | 버그 수정 |
| `refactor` | 동작을 유지하면서 코드 구조 개선 |
| `docs` | 문서 추가 또는 수정 |
| `test` | 테스트 추가 또는 수정 |
| `chore` | 설정, 의존성, 개발 도구 변경 |

## 이슈 제목

`[타입] 제목` 형식으로 작성한다. 이슈 템플릿의 제목에는 공통 타입만 사용한다.

```text
[feat] 상담 완료 기능 추가
[fix] 상담 요청 중복 생성 방지
```

## 작업 브랜치명

`타입/이슈번호-작업명` 형식으로 작성한다. 이슈가 없으면 `타입/작업명`으로 작성한다. 작업명은 영문 소문자로 쓰고 단어는 하이픈(`-`)으로 연결한다.

```text
feat/12-complete-consultation
docs/update-readme
```

## 커밋 메시지

`타입: 변경 내용` 형식으로 작성한다. 콜론 뒤에는 공백 한 칸을 넣고, 무엇을 바꿨는지 짧고 구체적으로 적는다.

```text
feat: 상담 완료 기능 추가
test: 이미 완료된 상담의 재완료 요청 검증
```

## PR 제목

이슈가 있으면 `[#이슈번호][타입] 제목`, 이슈가 없으면 `[타입] 제목` 형식으로 작성한다. PR로 이슈를 완료하는 경우 본문 맨 아래에 `Closes #이슈번호`를 적는다.

```text
[#12][feat] 상담 완료 기능 추가
[docs] README 실행 방법 정리
```
