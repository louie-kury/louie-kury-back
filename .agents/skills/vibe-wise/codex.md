# 프로젝트에 포함된 Codex 스킬

- 시작/재개는 `$vibe-wise`, 확인 후 초기화는 `$vibe-wise-reset`이다. 전역 플러그인 설치에 의존하지 않는다.
- 안내 문서는 이 SKILL.md와 같은 폴더에 있다. Read/Glob은 현재 사용 가능한 파일 읽기·검색 도구로 바꿔 사용한다.
- 가능한 질문 도구나 대화로 물어보고 답변을 기다린다. 질문을 반복하거나 미응답을 선택으로 간주하지 않는다.
- 새 자동 복원 훅은 추가하지 않았다. 새 세션/압축 후에는 필요할 때 이 스킬과 `.vibe-wise/progress.md`의 미정 사항을 확인한다.
- 사용자의 언어로 짧고 쉽게 설명한다. 계획 문서는 저장소의 `docs/ai/templates/spec.md`를 참고해 목적·선택지·사용자의 선택 이유·실패 조건·완료 기준을 기록한다. 학습 메모와 팀이 공유할 기능 명세를 구분한다.

- planner로 호출된 경우 설계만 담당한다. 질문/선택지를 메인에게 반환하고 사람이 답한 결과를 전달받는다. 동작 가이드의 구현 단계는 planner에게 코드 수정 권한을 주지 않는다. phase=docs-sync에서는 확인된 동작을 문서에 반영하고 새로운 결정을 임의로 추가하지 않는다.
