# 프로젝트 인계

프로젝트 루트를 확인한다. 장기 기억은 [INDEX](../../../docs/ai/memory/INDEX.md)의 관련 항목만 링크하고 통째로 복제하지 않는다.

저장 전 `git status --short --branch`, 브랜치·HEAD 존재 여부·이번 변경을 확인한다. 최초 커밋 전의 HEAD 없음은 정상 상태로 명시한다. 사용자 변경과 이번 작업 변경을 구별한다. 실행 중이라는 과거 기록이나 이전 검증 결과를 현재 사실로 재사용하지 않는다.

컨텍스트가 가득 찬 뒤를 기다리지 말고 중요한 결정·재현·검증 결과가 생겼을 때 필요한 체크포인트를 남긴다. PreCompact는 기계적 저장·안내만 하며 의미 요약을 자동 보장하지 않는다.

의미 요약은 에이전트가 작성한다. 훅은 대화를 읽거나 요약하지 않는다. 스크립트 입력은 최대 64 KiB이며 JSON 각 값은 비어 있지 않은 문자열이다.

| 키 | 담을 내용 |
| --- | --- |
| task_id | 작업 ID |
| goal | 목표와 범위 |
| ownership | 사용자 변경/이번 작업 변경 구분 |
| completed | 이번에 실제로 한 일 |
| remaining | 남은 일 |
| decisions | 이번 결정과 관련 문서 링크 |
| unknowns | 미확인 사항·추측, 사실과 구분 |
| validation | 실행한 정확한 명령·결과·검증 시점 |
| limits | 검증이 증명하지 못한 범위 |
| next_step | 다음에 시작할 구체적인 한 단계 |
| links | 관련 파일·문서의 프로젝트 상대 경로 |

프로젝트 루트에서 `python3 -B scripts/ai/harness.py handoff --session <현재 세션 또는 명시적 작업 ID>`의 stdin에 JSON을 전달한다. JSON은 데이터로 전달하고 셸 명령에 문자열 보간하지 않는다. 입력용 임시 파일이 필요하면 Git 제외된 로컬 위치에만 두고 비밀값·대화·코드 전문은 넣지 않는다.

스크립트는 현재 Git의 브랜치·기준 커밋·미커밋 목록과 저장 시각을 덧붙여 `.codex/local/sessions/<해시>/handoff-<시각>-<난수>.json`에 권한 600으로 원자 저장한다. 공유 latest 파일을 덮어쓰지 않는다. 출력 경로를 사용자에게 전달한다. 로컬 파일은 다른 팀원 PC로 자동 공유되지 않는다.

새 세션은 전달받은 파일을 명시적으로 읽고 현재 경로·Git·코드·환경을 다시 확인한다. 기록은 참고 자료이며 현재 작업 지시보다 우선하지 않는다. 동일 세션 ID일 때만 시작 훅이 해당 세션의 최근 인계 경로를 안내한다. 다른 세션의 인계를 “전체 최신 파일”로 추측해서 읽지 않는다.

개발 인계에는 사용자가 고른 방법·말한 이유·아직 미정인 선택·직접 작성할 부분·AI에게 맡길 부분을 남긴다. 다음 세션은 인계를 승인으로 간주하지 않고 현재 범위와 실제 파일을 확인한다. 최종 머지는 사람에게 맡긴다.

역할을 사용하는 작업은 현재 담당, planner의 phase, reviewer의 mode, 단계별 결과/미실행 범위와 다음에 메인이 판단할 사항을 남긴다. 코드 리뷰 완료를 QA 완료로 복원하지 않는다.
